# Aris Angelo Don Florentino - Portfolio 

A personal portfolio website built with a **Neo-Brutalist** design aesthetic. This project showcases my work, skills, and experience as a Front-end Developer.

## Neo-Brutalism 

This portfolio is a deliberate departure from the soft, minimalist trends that dominate modern web design.

## Tech Stack 

- **Framework:** React
- **Styling:** Tailwind CSS
- **Icons:** React Icons
- **Animations:** CSS Transitions & Tailwind utility classes

## Features 

- **Fully Responsive:** Adapts Seamlessly from mobile to desktop with a custom full-screen mobile menu.
- **Dark Mode:** A fully functional light/dark theme toggle that switches the entire color scheme, including borders and shadows.
- **Dynamic Content:** All text, project data, work history, and skills are managed in a single content option file for easy updates.
- **Interactive UI**
